PART 1: CONTEXT & PHILOSOPHY (To be included in the prompt)
The Core Insight
Institutional traders and informed money often use options to gain leveraged, stealthy exposure before committing large cash positions. Because options trading does not immediately move the underlying stock price as much as buying shares, a surge in call option volume and OI can precede a significant price move by 15 minutes to several hours (or even 1-2 days). The 35-minute lead time observed in SBIN (1000 CE volume spike at 11:55 AM, first big stock candle at 12:30 PM) is a classic example.

The Challenge
Raw options volume is ambiguous – it could be buying or selling. The true signal comes from OI change combined with price direction of the option itself and the underlying. The tool must distinguish between:

Fresh long call buying (bullish → OI up, option price up, underlying up or flat)

Short covering (bullish but fading)

Call selling (bearish → OI up, option price down, underlying down)

Target User
Institutional traders, proprietary desks, and sophisticated retail traders who monitor the market in real-time (pre-market to 3:30 PM IST). They need a dashboard that flags potential accumulation before the stock's first large candle.

3.2 Unusual Activity Scoring (Detailed)
For each strike, every minute compute:

python
def compute_activity_score(strike_data, underlying_data):
    # 1. OI change % (from previous day)
    oi_change_pct = (strike_data.oi_current - strike_data.oi_previous_day) / strike_data.oi_previous_day * 100
    oi_score = min(oi_change_pct / 20, 1.0) * 40  # 20% change gives 40 points

    # 2. Option price momentum (last 5 minutes)
    price_change_pct = (strike_data.last_price - strike_data.price_5min_ago) / strike_data.price_5min_ago * 100
    momentum_score = min(max(price_change_pct, 0) / 5, 1.0) * 20

    # 3. Underlying VWAP deviation
    vwap_dev = (underlying.last_price - underlying.vwap_5min) / underlying.vwap_5min * 100
    vwap_score = (1 - min(abs(vwap_dev) / 2, 1.0)) * 20  # lower deviation is better

    # 4. Delivery volume spike (if available)
    delivery_ratio = underlying.delivery_volume_today / underlying.avg_delivery_volume_5days
    delivery_score = min(delivery_ratio / 2, 1.0) * 10

    # 5. Technical trigger: underlying above 20-period EMA (5-min chart)
    ema20 = ta.ema(underlying.close, length=20, timeframe='5min')
    trigger = 10 if underlying.close > ema20 else 0

    total = oi_score + momentum_score + vwap_score + delivery_score + trigger
    return min(total, 100)
3.3 Fresh Long Buying vs Selling Detection
Use the OI + Option Price + Underlying Price matrix:

OI Change	Option Price Change	Underlying Price Change	Interpretation	Signal
▲ (>5%)	▲ (>2%)	▲ or flat (>0%)	Fresh long call buying	Strong Bullish
▲ (>5%)	▲ (>2%)	▼ (<0%)	Bearish hedge or speculation	Weak Bullish
▲ (>5%)	▼ (<-2%)	▼ (<0%)	Call writing (bearish)	Bearish
▼ (<-5%)	▲ (>2%)	▲ (>0%)	Profit taking / long unwinding	Bearish (exhaustion)
The tool should display an icon: 🟢 (strong buy) / 🟡 (speculative) / 🔴 (sell signal).

3.4 Leading Indicator Time Window
The tool's main innovation: detect before the first large stock candle.
Define "large candle" as a 5‑minute bar where volume > 1.5x 20‑period average AND price change > 0.5%.
The tool should flag signals up to 60 minutes before such a candle forms, by monitoring:

OI spike without equivalent price move in the underlying

Call OI accumulating at a strike that is out-of-the-money by 1–3% (ATM or slightly OTM) – this is where directional bets have maximum gamma.

3.5 Backtesting Logic
For each flagged event (timestamp, stock, strike), measure forward returns:

Underlying return after 15 min, 30 min, 60 min, end-of-day.

Compute win rate and average return per LIS decile.

Store in a PostgreSQL table for continuous validation.
